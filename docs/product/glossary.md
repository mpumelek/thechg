# Domain glossary

Status: Draft. Owners: Product owner and Church leadership. Confirm language translations and preferred spellings with country representatives.

| Term | Meaning in this platform |
|---|---|
| Church / denomination | The single organization operating the platform initially; represented by `ChurchId` |
| Country | National operating unit with local configuration, currency, timezone and legal obligations |
| Circuit | Organizational unit containing branches, beneath a country |
| Branch | A local congregation and the primary operational scope for membership and manual giving |
| Member | A person in the formal Church membership process or active membership; not an anonymous visitor |
| Registration/application | Administrator-created record awaiting governance decision |
| Approved | Leadership has accepted the registration into the formal joining process; not necessarily active |
| Active | Membership requirements completed or an authorized exception recorded |
| New Member Journey | Configurable orientation/curriculum process attached to an approved member |
| Buddy | Eligible person formally assigned to support a journey, with capacity and dated assignment history |
| iMihlangano | Church small/cell group; configurable schedule and dated member allocations |
| Amalunga | Church leadership category; precise permissions are configured, not inferred from the title |
| Abafundisi / Abafundikazi | Church leadership categories; precise permissions are configured |
| Fund | Purpose to which a charitable contribution is allocated |
| Contribution | Giving transaction; distinct from event ticket or store sale |
| Batch | Operational grouping of manual contributions for capture/posting/reconciliation |
| Posted | Finalized transaction; corrections use reversal/adjustment rather than edit |
| Approval request | Reusable record of decision assignment and outcome; domain module owns resulting state |
| Organizational scope | The unit at which a permission is granted, including permitted descendants where policy allows |
| Pastoral case | Restricted care record, not visible to ordinary branch administration |
| Outbox | Durable record of asynchronous work saved with the business transaction |

Avoid using “visitor” as a synonym for “new member.” Avoid using “approval” as a synonym for journey completion. Avoid treating household relationship as automatic permission to see another person's giving.
