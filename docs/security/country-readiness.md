## Entry gate for each country

Country representative signs off localized workflows; counsel/information officer signs off privacy and cross-border assessment; finance signs off payment and receipt treatment; operations tests latency, support and backup restore; security tests scope isolation; at least one branch completes UAT and offline recovery rehearsal. Stagger rollout so a failure in one country does not block or corrupt another.
